# Figure reproduction assets

This directory isolates manuscript-facing material from the runnable model package.

Publication-approved manuscript figures can be added here later. Install optional figure tooling only when a retained figure script requires it:

```bash
pip install -r 01OmicPro_code/requirements-figures.txt
```

When adding a figure, place its source script and any non-sensitive input description in a dedicated subdirectory, record the exact input/result names in that subdirectory's README, and commit the final vector or raster asset only when publication rights permit.
