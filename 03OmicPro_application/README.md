# OmicPro application recipes

This directory is for users applying a released OmicPro checkpoint, rather than retraining the model or reproducing manuscript figures.

- [predict_from_checkpoint](predict_from_checkpoint/README.md) explains phenotype-free inference.
- [custom_dataset_template](custom_dataset_template/README.md) explains how to prepare a new three-omics dataset before training.

Install the package from the repository root before using either recipe:

```bash
pip install --no-deps -e 01OmicPro_code
```
